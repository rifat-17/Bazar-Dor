🛒 বাজার দর | BazarDor

দৈনন্দিন প্রয়োজনীয় পণ্যের বাজারমূল্য এক নজরে

BazarDor is a web application that helps users explore the latest prices of everyday essential products in Bangladesh. Users can browse products by category, compare current and previous prices, track price changes, and view market-wise price information through a simple and responsive interface.


## 🚀 Technologies Used

- **Next.js 16** — React framework for building the application,
- **React** — Component-based user interface,
- **TypeScript** — Type-safe JavaScript development,
- **Tailwind CSS** — Responsive styling and modern UI design,
- **HeroUI** — UI components,
- **Better Auth** — User authentication, including email/password and Google sign-in,
- **MongoDB** — Database for authentication data,
- **REST API** — Fetching product categories, prices, and market information,
- **Vercel** — Application deployment


## ✨ Key Features

### 1. 📊 Real-Time Price Information
Explore product prices and compare today's prices with historical prices to understand market trends.

### 2. 🗂️ Category-Based Browsing
Browse essential products by category, including rice, lentils, oil, vegetables, fish, meat, and eggs.

### 3. 📈 Price Change Tracking
Identify products with rising or falling prices, including percentage changes, to make more informed purchasing decisions.

### 4. 🔍 Product Details and Market Comparison
View individual product details, average and minimum/maximum prices, and market-wise price information organized by division.

### 5. 🔐 User Authentication
Sign up, sign in, and manage your authentication session using Better Auth, with support for email/password and Google sign-in.




*Note: Market prices are indicative and may vary depending on market conditions.*
